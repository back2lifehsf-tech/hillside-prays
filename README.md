# Hillside Prays

A WordPress plugin for Hillside Baptist Church: people ask for prayer or help through one simple form, the Care team dispatches and logs every request, and the prayer team prays through the week.

It starts a throwaway WordPress in your browser with the plugin installed and sample data loaded. Nothing is real, and it resets when you close the tab.

- The Pray page opens first (that's what the church sees).
- wp-admin > Hillside Prays: the Care inbox, with one request waiting for approval and one overdue (red).
- Demo users: `darlene` (Care) and `team1` (prayer team), password `demo-prayer-2026`.

## Install on a real site

1. Back up the site.
2. Plugins > Add New > Upload Plugin > `dist/hillside-prays-wordpress.zip` > Activate.
3. Publish the draft "Pray" page and add it to the menu.
4. Hillside Prays > Settings: set the Care email.
5. Users > Add New: "Prayer Team" role for the team, "Hillside Care" for Care leads.

## Updating

New version: replace the files, update `dist/hillside-prays-wordpress.zip`, commit and push. The demo link always installs the zip in `dist/`.
